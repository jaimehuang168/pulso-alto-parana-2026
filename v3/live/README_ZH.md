# Pulso 即時統計與報表管理

## 持續更新，不等調查結束

`live/` 是需登入的統計畫面，`live/control.html` 是管理者專用代號／報表／連續觀看控制台。`live-demo/` 及 `Pulso_LIVE_DEMO_ES.html` 是完全隔離的合成資料展示，不會在正式 API 失敗時偷偷作為替代。

`4 ciudades` 同時查詢並呈現四市各自的樣本；電腦及電視以2×2顯示，窄螢幕以可捲動卡片保持可讀性。點城市可放大單城；`Rotación` 每15秒切換有權限的城市。自動查詢在上一請求完成後5秒再執行，管理者另有非敏感 revision 事件提示。網路延遲會影響更新速度。`Pausar` 只暫停畫面，不停止訪員收件。PNG/CSV是當下快照，不是持續更新的檔案。

各城市獨立計算百分比分母。不把四市比例相加，不把沒有覆蓋的地點當成零票，不計入尚未收到的手機待傳。這是樣本統計，不是官方選舉結果或勝選判定。

## 內部、代號預覽與外部觀看

- `Admin · nombres reales`：管理者內部真名與Lista核對。
- `Privada · códigos`：管理者的代號預覽，保留NO DIFUNDIR標示。
- `Viewer · canal autorizado`：只含代號的授權城市彙總；必須同時符合角色範圍、外部結果開關、問卷／代號版本、發布政策、時點及連續觀看授權。

內部觀看不要求投票結束。外部代號化不等於取得發布許可。外部資料失去及時授權確認後會隱藏；既有下載檔無法遠端收回。更改URL不能取得管理權限。

## 控制台

管理者從即時看板按 `Administrar códigos / informes`，可使用同一登入工作階段。依城市確認真名／代號對照，設定政策、Viewer總開關和連續頻道。頻道單次最多24小時；修改政策或代號後，需重新確認受影響的授權，不沿用舊版本。

`Crear corte interno y externo` 另建立共同截止時間的凍結快照。內部CSV會取得所有分頁並對帳，外部HTML/PNG/CSV使用另一份僅允許代號欄位的資料。HTML可在瀏覽器另存PDF；不要列印管理者整個畫面作為外部報告。固定報告發布與連續頻道是獨立操作。本控制台不改變調查收件狀態。

## 必須安裝的後端

先核對同一個正式Supabase專案並完成真正備份。V3基礎004–008已存在時，按順序執行 `009_v3_reports.sql`、`010_v3_live_board.sql`、`011_v3_live_console.sql`。如果只有完整V2且尚未作業，先依原V3切換流程安裝 `V3_UPGRADE_EXISTING.sql`。既有V3不得重跑該基礎升級，更不可重跑V2初始化或刪表。

009會撤回舊版含真名的衍生Viewer快照，但不刪除原始問卷；010提供連續看板；011提供管理控制台唯讀狀態及Viewer授權到期的有效期限制。安裝不開收、不改真實回答、不自動核准外部發布。另須部署V3的 `field-enrollment` 函式並保留同專案伺服器Secrets；前端只能使用公開金鑰。

正式靜態前端沿用 `../v3/config.js` 與 `../v3/vendor/supabase.js`。正式API不存在或工作階段被拒絕時，显示待安裝／無權限，不提供合成數字。
