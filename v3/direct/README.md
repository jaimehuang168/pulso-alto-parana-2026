# V3.1 直接使用

使用者明確要求：核對013；公司管理者與使用者登入後直接使用，不再執行Activate。

- 不再顯示、代填或要求公司完成版本啟用的三項表單。
- Supabase仍僅由指定Super Admin操作。一次性技術部署檢查013並設定直接使用模式；不假填備份、待傳或實機驗收。
- 保留所有身分、角色、城市、任務、原始回答、稽核及已保存公司紀錄。
- 不開放收件、不變更日期、不開啟調查點或對外發布。
- 有舊問卷、資料不一致或非準備状态時，不強制覆蓋；整份安裝交易回復。
- 關閉舊V2介面後，裝置中的V2待傳不會自動遷入V3，也不會被本次刪除。不得清除未核對的本機資料。
- 未能連線至正式資料庫時，不以已發布前端或401回應宣称013完整安裝。以安裝回傳的module_013_before/after及已登入狀態為準。
