# Leer antes de empezar

El manual completo contiene el recorrido de instalación (páginas 4–13), uso
móvil (14–16), coordinación y Viewer (17–18), cierre e incidencias (19–20),
mantenimiento y fuentes (21–24). La guía de dos páginas es para encuestadores.

El primer administrador entra con su correo real. El resto de cuentas creadas
por la app puede entrar con su código. Los datos de ensayo y producción deben
estar separados. Nunca escriba claves ni datos de campo en una copia del manual
que vaya a publicar con el código.

La casilla de progreso de las guías HTML se guarda únicamente en el navegador
cuando lo permite y no acredita que el backend haya superado pruebas.
