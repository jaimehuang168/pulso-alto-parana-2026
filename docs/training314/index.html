Empiece por la tarea que necesita

Administración: mire el primer video. Encuestadores y personas con acceso de lectura: use el segundo. Pulse reproducir, active el sonido y pause antes de realizar cada paso. Los capítulos permiten volver directamente a una tarea.

Para leer con calma, abra el manual ilustrado. Toque una imagen para ampliarla. Los recuadros ámbar, cuando aparecen, señalan el campo indicado. El resultado esperado al final de cada tarea le permite comprobar si terminó correctamente.

No practique con respuestas ficticias en producción. Use únicamente el entorno de formación autorizado. Nunca comparta su contraseña, su frase local ni la cuenta de otra persona. Para dudas, consulte a coordinación.
